# CPU SIMD kernels and differential tests

**Goal:** Implement AVX2/FMA and AVX-512 dense-f32 CPU kernels, exercise the reference kernels in automated comparisons, integrate a working CPU executor, and measure throughput on available hardware.

**Architecture:** Keep the scalar f64 reference independent. CPU kernels consume checked slices, choose ISA at runtime, and contain narrowly scoped target-feature functions. The backend binds immutable inputs and a disjoint writable output once per operation. Logical model blocks remain unchanged. Parallel matrix work uses a persistent worker pool; per-core SIMD performance and whole-operation performance are reported separately.

**Scope:** Current executable dense-f32 operators: linear, RMSNorm, SwiGLU/GeGLU, residual, rotate-half RoPE, row lookup, append and causal full/windowed grouped-query attention. LTQ kernels remain independent reference tests; packed LTQ execution, quantization, GPU and missing model algorithms are separate work. Physical hardware ceiling is a measurement target, not an unverified completion claim.

**Constraints:** Rust 1.89, portable fallback, no global target-cpu=native requirement, explicit CPU feature checks, tail/unaligned support, no family-specific branches, finite-output checks at the executor boundary, committed state protected on failure. Test each available ISA explicitly; unsupported modes must error safely. Preserve K/V sharing and memory reporting; attention must not allocate unreported full-history scratch.

## Tasks

- [x] Matrix kernels: checked f32 API, scalar oracle tests, multiple independent accumulators and register blocking for AVX2/AVX-512, separate decode and batch reuse; odd shapes and biases.
- [x] Vector kernels: RMSNorm, residual, gated activation, RoPE; differential tests across tails, unaligned starts, unit-offset norm, clamps and positions.
- [x] Bindings: safe bulk access to up to four input slices and one disjoint activation output, readonly weights/tokens, bulk append; alias/descriptor/lifetime regression tests.
- [x] CPU executor: explicit Op dispatch, efficient attention without repeated QK per value coordinate, preallocated or bounded scratch, reusable thread pool for large matrix operations.
- [x] Integration: reference and each SIMD ISA run the independent decoder fixture at all chunkings; include shared/derived state and failure recovery.
- [x] Benchmark: release executable with explicit ISA, shape, iteration and thread settings; report useful GFLOP/s and weight bandwidth with hardware/compiler context, no CI speed thresholds. Compare cache-resident and streaming matrices, and representative full operations.
- [x] Validate: workspace tests, release differential tests, warnings-denied clippy, Rust 1.89 all-target build, fmt, code review and documented measured limitations.

## Implementation and verification record

- Added runtime-checked Scalar/AVX2+FMA/AVX512F modes and allocation-free pure dense-f32 kernels. Reference functions remain independent and are used by differential tests. Broad vector-tail/unaligned/long-reduction tests run each available mode.
- Matrix implementation uses independent GEMV accumulators, small-token register blocks, SIMD-transposed stack packing and outer-product prefill. Feature-stripe parallelism preserves token reuse; private lifetime-bound raw output pointers represent disjoint columns without overlapping mutable slices. Extra stack packing is fixed at8KiB/16KiB per AVX2/AVX512 worker.
- Added safe host bulk-binding borrows, slice append, shared shape-level eligibility checks, and CpuExecutor with explicit persistent Rayon workers. Large decode attention partitions heads; prefill partitions query rows.
- All supported CPU modes execute the independent decoder fixture for32 input partitions. Shared/derived state, tied weights and failed-step recovery now run through CPU as well as reference execution.
- Independent review found an attention cancellation/scale-amplification issue. Reproduced RED, fixed with same-pass absolute-product error estimation and rare f64 dot fallback, verified GREEN across scalar/vector widths. Reviewer independently confirmed the fix. Final matrix/attention partition reviews found no outstanding actionable issues.
- Performance work was measurement-driven: packed AVX512 prefill roughly doubled initial single-core throughput, and feature-stripe parallelism improved multi-core reuse. Bounded attention tiles avoid repeatedQK; independent weighted-value chains and ISA-specialized loops improve throughput.
- Final verification:134 workspace tests passed;38 release CPU/exec tests passed; fmt, git diff whitespace check, warnings-denied workspace/all-target clippy and Rust1.89 workspace/all-target build passed.
- Reproducible benchmarks and observed read/FMA calibration are in CPU examples. Results, full commands and numerical limits are documented in docs/RU/cpu-performance.md, docs/EN/cpu-performance.md and docs/benchmarks/2026-10-31-cpu.txt. No universal physical-ceiling or end-to-end generation claim is made.
