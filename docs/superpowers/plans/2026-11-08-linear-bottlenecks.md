# Устранение накладных расходов GEMV/GEMM

Завершено 2026-11-08. Область: текущий Rust/C/LLVM путь, без переноса движка на C/Vulkan. Исходная версия включала незакоммиченные изменения; её снимок и отдельный diff этой работы сохранены в отчёте (`../../benchmarks/linear-bottlenecks-2026-11-08/README.md`).

- [x] Вынести постоянную геометрию из prepared worker и передавать число строк явно. Проверены хвосты, нечётные сетки и численные результаты. Самостоятельного ускорения арифметики не установлено.
- [x] Проверить вынос стека частичного выходного тайла. Эксперимент отклонён: уменьшение стека сопровождалось замедлением GEMV. `prepared.c` восстановлен побайтово.
- [x] Подключить подготовленные веса к графу через общий DenseLayout и backend hook. Сохранить одного владельца и row-major для смешанных потребителей; учесть padding до выделения памяти. Новые тесты сначала воспроизвели отсутствие поведения, затем прошли.
- [x] По свежему профилю заменить последовательную проверку конечности векторизуемой редукцией. Проверки NaN/Inf сохранены; граничные случаи проверены на x86 и ARM.
- [x] Провести перемежённые сравнения 1/8/16/32 потоков, AVX2/AVX-512/base, cached/streaming GEMV, GEMM и хвостов. Отдельно проверить полный граф и Adaptive. Единица — TFLOPS; ограничения и небольшие регрессии опубликованы.
- [x] Release workspace: 280 тестов; default workspace: 248; AArch64 и ARMv7 под QEMU: по 27. Clippy, fmt, независимое ревью. Проверить отсутствие посторонних правок и перенести 12 файлов в рабочий каталог; повторно выполнить release workspace после переноса.

Итог: устранены повторная упаковка эксклюзивных Linear-весов в графе и значительная часть расходов проверки результатов. Большой GEMM полного графа ускорился на 6–14%, cached GEMV — на 20–27%. Самостоятельные арифметические кернелы остались примерно на прежнем уровне. Физический потолок, скорость реальных моделей и оптимальность всех расписаний не заявляются.
