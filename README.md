# lumen-rs

**lumen-rs** — движок инференса больших языковых (LLM) и мультимодальных моделей на Rust и CUDA C++, спроектированный для **гибридного выполнения (offloading)**: когда модель не помещается в видеопамять одной потребительской видеокарты (16–32 ГБ VRAM), часть её весов и состояний размещается в системной памяти (RAM) или на NVMe-накопителе, а вычисления распределяются между GPU и CPU.

Documentation: **[Русский (docs/RU/)](docs/RU/architecture.md)** · **[English (docs/EN/)](docs/EN/architecture.md)**

## Состояние проекта

Сейчас закладывается фундамент. Работают разбор конфигурации и `lumen inspect`, структурные описания моделей, проверка контейнера и эталонное декодирование LTQ, расчёт размеров памяти и планирование арен. Есть несколько эталонных вычислительных ядер.

**Генерация пока не реализована.** CPU/CUDA-бэкенды, подготовка `Program`, offload, сервер и квантователь ещё предстоят. Распознавание конфига модели не означает поддержку её исполнения; остальные команды CLI явно сообщают об отсутствии реализации.

## Основные принципы

- Архитектуры моделей собираются из переиспользуемых блоков и операций. Общие механизмы не содержат ветвлений по названиям семейств.
- Хранение данных и устройство вычислений задаются отдельно. Подготовка исполнения должна проверить поддержку размещения, зависимости и бюджет памяти.
- `Program` — подготовленное расписание вычислений и пересылок. Первый рабочий путь не требует общего оптимизатора, авторазмещения или единого CUDA Graph.
- Память учитывается по физическим ресурсам и времени жизни. Q/K/V — роли входов attention; они не требуют фиксированного числа хранилищ.
- Корректность проверяется относительно эталонных вычислений и независимых реализаций моделей. Оптимизации принимаются по измерениям.

LTQ — формат квантованных весов проекта; его спецификация и исследовательские результаты описаны отдельно. Предлагаемые механизмы исполнения и прогнозы производительности не являются отчётом о готовом движке.
